# M3 UI Spec

## Outcomes
Customer books, views, cancels or reschedules own appointment. Staff filters schedule, confirms/cancels/no-shows/checks in. Manager changes future booking schedule. Staff opens repair-order detail.

## In scope
M3 Task 5 UI/actions. Existing service APIs and permissions. Basic chronological schedule, not drag/drop calendar.

## Out of scope
S3 uploader/media UI, realtime, capacity booking, M4 inspection/quotation, M5 work/inventory.

## Constraints
Next.js App Router, existing shadcn/Base UI, server authorization, session-derived garage scope, Vietnamese UI.

## Verification
Targeted unit/integration, lint, typecheck, build, Playwright booking-to-check-in flow.
